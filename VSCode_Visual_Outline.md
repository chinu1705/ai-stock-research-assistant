## 📁 **PROJECT STRUCTURE**

### **Main Folders (12)**
```
ai-stock-research-assistant/
├── app/           # Different pages
├── components/    # Reusable pieces
├── lib/           # Helper tools
├── prisma/        # Database setup
├── public/        # Pictures/icons
├── types/         # Data definitions
├── contexts/      # Shared info
├── hooks/         # Code patterns
├── .next/         # Built program
├── node_modules/  # External tools
├── .git/          # Version history
└── .claude/       # AI settings
```

### **Key Files (50+)**
- Home page (`app/page.tsx`)
- AI analysis (`lib/gemini.ts`)
- Stock data (`lib/yahoo-finance.ts`)
- Database (`prisma/schema.prisma`)
- UI components (`components/ui/`)
- Charts (`components/stock/PriceChart.tsx`)
